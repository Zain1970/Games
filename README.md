# Games — 3D Adventure Mobile

لعبة مغامرات ثلاثية الأبعاد بأسلوب كرتوني، مبنية بـ Godot 4 وموجهة للجوال.

## الموجود حالياً
- 10 مراحل متدرجة الصعوبة.
- اختيار 5 شخصيات/ألوان.
- متجر شخصيات وفتح الشخصيات بالعملات.
- رصيد عملات محفوظ بين جلسات اللعب.
- حفظ أفضل نتيجة وأفضل وقت وحالة التقدم داخل `user://savegame.json`.
- نظام نقاط حفظ (Checkpoint): بعد فتح مرحلة جديدة يمكن العودة إليها لاحقاً.
- شاشة اختيار المراحل: المراحل المفتوحة يمكن البدء منها مباشرة، والمراحل غير المفتوحة تظهر بقفل.
- مهمة يومية: جمع 20 عملة للحصول على 50 عملة مكافأة.
- إعادة ضبط المهمة اليومية تلقائياً عند تغير تاريخ الجهاز.
- تحكم باللمس: أزرار يمين/يسار + سحب للحركة + زر للقفز.
- دعم لوحة المفاتيح على الكمبيوتر: WASD + Space.
- 3 أرواح مع إعادة إحياء عند السقوط أو الاصطدام.
- عقبات ثابتة ومخاطر متحركة وأعداء كرتونيون في المراحل المتقدمة.
- عملات قابلة للجمع.
- بوابة نهاية لكل مرحلة.
- شريط تقدم يوضح المسافة المتبقية داخل المرحلة.
- علامات Checkpoint مرئية بين المراحل.
- أيقونة تطبيق SVG مخصصة.
- زيادة صعوبة تدريجية.
- واجهة عربية: القائمة، HUD، الإيقاف المؤقت، الفوز، الخسارة، المتجر والإعدادات.
- إعدادات محفوظة للصوت والموسيقى والاهتزاز، مع تجهيز ربط المؤثرات لاحقاً.
- بدون أصول خارجية حالياً؛ المجسمات والبيئة يتم إنشاؤها بالكود.

## تشغيل المشروع
1. افتح المشروع في Godot 4.
2. شغّل `Main.tscn`.
3. اختبر التحكم باللمس على جهاز Android أو باستخدام المحاكي/الماوس حسب بيئة الاختبار.

## Android
من Godot استخدم Project > Export ثم أضف Android Export Preset. لاختبار الجهاز يمكن استخدام APK، وللنشر على Google Play يجب إعداد نسخة Android موقعة وإخراج AAB وفق إعدادات التصدير المناسبة.

## ملاحظة مهمة
الكود محفوظ في GitHub، لكن لا أعتبر نسخة Android جاهزة للنشر حتى يتم فتح المشروع في Godot وتشغيله فعلياً واختباره على جهاز Android. بعد الاختبار يمكن معالجة أي أخطاء تظهر في المحرك ثم تجهيز نسخة Release.

## الخطوات التالية
- إضافة أصوات وموسيقى فعلية.
- إضافة اهتزاز فعلي عند الاصطدام والقفز/المكافآت.
- تحسين واجهة الجوال وإضافة أزرار حركة مخصصة.
- إضافة مؤثرات بصرية وحركات للشخصية.
- تحسين الأداء للأجهزة الضعيفة.
- اختبار شامل داخل Godot ثم تجهيز إعدادات Android وGoogle Play.
