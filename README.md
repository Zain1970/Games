# Games — 3D Adventure Mobile

لعبة مغامرات ثلاثية الأبعاد بأسلوب كرتوني، مبنية بـ Godot 4 وموجهة للجوال.

## الموجود حالياً
- 10 مراحل متدرجة الصعوبة.
- شخصية 3D قابلة لاختيار 5 ألوان/أشكال لونية.
- حفظ أفضل نتيجة ووقت ولون الشخصية داخل `user://savegame.json`.
- تحكم باللمس: سحب للحركة وزر للقفز.
- دعم لوحة المفاتيح على الكمبيوتر: WASD + Space.
- 3 أرواح مع إعادة إحياء عند السقوط.
- عقبات ثابتة ومخاطر متحركة.
- عملات قابلة للجمع.
- بوابة نهاية لكل مرحلة.
- زيادة صعوبة تدريجية وإضافة مخاطر في المراحل المتقدمة.
- واجهة عربية: القائمة، HUD، الإيقاف المؤقت، الفوز، وإعادة المحاولة.
- بدون أصول خارجية حالياً؛ المجسمات والبيئة يتم إنشاؤها بالكود.

## تشغيل المشروع
1. افتح المشروع في Godot 4.
2. شغّل `Main.tscn`.
3. اختبر التحكم باللمس على جهاز Android أو باستخدام المحاكي/الماوس حسب بيئة الاختبار.

## Android
من Godot استخدم Project > Export ثم أضف Android Export Preset. لاختبار الجهاز يمكن استخدام APK، وللنشر على Google Play يجب إعداد Gradle وإخراج AAB وتوقيعه بمفتاح Release غير تجريبي.

## ملاحظة مهمة
الكود محفوظ في GitHub، لكن لا أعتبر نسخة Android جاهزة للنشر حتى يتم فتح المشروع في Godot وتشغيله فعلياً واختباره على جهاز Android. بعد الاختبار يمكن معالجة أي أخطاء تظهر في المحرك ثم تجهيز نسخة Release.
