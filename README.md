# Games — 3D Adventure Mobile Prototype

لعبة مغامرات ثلاثية الأبعاد بأسلوب كرتوني، مهيأة للتصدير إلى Android باستخدام Godot 4.

- عالم 3D مولد بالكود
- شخصية وحركة وقفز
- تحكم باللمس للجوال
- عقبات وعملات وبوابة نهاية
- واجهة عربية

التشغيل: افتح المشروع في Godot 4 وشغّل Main.tscn.

لإخراج Android: جهّز Android SDK داخل Godot ثم استخدم Project > Export لإخراج APK أو AAB، واختبر نسخة Release قبل النشر.
